# 90 秒中文演示脚本

## 成片规格

- 画面：16:9，1920×1080，30 fps
- 时长：85-95 秒
- 内容：真实中文本地候选，不使用预览数据源冒充集成结果
- 声音：中文旁白与中文字幕；如果语音工具不可用，保留完整字幕和界面原声为空的可交付版本
- 真实性：固定样例、模拟证据、无真实进程控制必须持续可见

## 分镜与旁白

| 时间 | 画面与操作 | 中文旁白 |
|---|---|---|
| 0-8 秒 | 标题进入，停留在初始故障页；顶部三枚可信标签清晰可见。 | “本地 API 报错时，真正难的不是重启，而是证明：为什么出错、是否经过批准、结果是否真的恢复。” |
| 8-20 秒 | 指向 `order-api`、`api-error-burst`、已降级状态和五阶段进度。 | “这是 OpenDashboard 的本地固定样例演示。`order-api` 已降级；所有外部信号都是确定性模拟，不是实时集成。” |
| 20-36 秒 | 点击“运行只读排查”，展示四类证据卡。 | “第一步只读排查。系统把 HTTP、追踪、日志和资源信息统一成一份脱敏证据，不连接任何实时提供器。” |
| 36-46 秒 | 缓慢移动到提供器来源区，突出固定样例、模拟与已脱敏标签。 | “每条证据都保留来源和固定样例、模拟、已脱敏状态。可信不是因为界面看起来实时，而是因为边界始终可见。” |
| 46-58 秒 | 点击“申请模拟重启”，停留在待审批状态。 | “恢复建议不会直接执行。系统先打开审批门，没有明确授权，就不会确认下一步。” |
| 58-70 秒 | 点击“批准模拟重启”，展示审批 ID、模拟操作和仍为已降级的目标。 | “批准只记录同意并确认模拟操作，目标仍然是已降级。批准不等于恢复，也不会控制真实进程。” |
| 70-81 秒 | 点击“验证恢复结果”，展示健康和已恢复状态。 | “最后验证结果，而不是相信承诺。目标变为健康，故障变为已恢复，前后状态都有证据。” |
| 81-90 秒 | 点击“查看脱敏报告”，展示五条审计事件、未验证声明和报告摘要并定格。 | “一份本地脱敏报告把来源、审批、模拟操作、验证和未验证声明放在一起。这就是 OpenDashboard 的价值：让自动化可解释、可审批、可追溯。” |

## 必拍验收画面

1. 初始页的固定样例、模拟证据、实时适配器待开发标签。
2. 四类脱敏证据卡。
3. 待审批状态与审批记录。
4. 模拟操作已确认，以及仍为已降级的目标。
5. 健康/已恢复状态。
6. 五条审计事件、脱敏报告摘要及未验证声明。

## 停止条件

如果任一步跳过审批、固定样例标签消失、报告含敏感字段、控制台出现错误、移动端关键操作被遮挡，或录制画面来自预览数据源而不是生产入口，则停止制作并修复；不得用旁白掩盖缺口。
