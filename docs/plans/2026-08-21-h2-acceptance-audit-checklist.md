## 0. 六个必需页面（`02_应用交付与验收要求.md` 第 5 行，逐字）

```
系统总览、异常事件中心、异常诊断详情、数据分析、运维助手、报告中心
```

同文件另三条硬要求：

- 须交付浏览器可访问的 Web 应用，**不接受**仅 Notebook、命令行脚本或桌面客户端。
- 须支持本地离线部署、一键启动、导入测试 CSV、中文变量展示、结构化结果导出、诊断报告导出。
- 符号约定：PCC 正值上网、负值下网；储能正值放电、负值充电。

**已发现的偏差**：`H2Shell.tsx` 的导航标签有三项与上述官方名不一致
（异常事件 / 诊断详情 / 运行助手 ↔ 异常事件中心 / 异常诊断详情 / 运**维**助手），
且与页面内标题自相矛盾（`EventsPage` 自称「异常事件中心」）。已转 C 轨并入 C1。
