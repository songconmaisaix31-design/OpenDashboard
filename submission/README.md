# T3 Submission Package

This directory is the claim-safe competition handoff for the integrated local
fixture candidate. It does not contain an executable plugin, deployment
configuration, or live provider integration.

## Review order

1. [`SUBMISSION_COPY_ZH.md`](./SUBMISSION_COPY_ZH.md) — Chinese competition copy.
2. [`../docs/demo/DEMO_SCRIPT_ZH.md`](../docs/demo/DEMO_SCRIPT_ZH.md) — Chinese 90-second recording script.
3. [`SUBMISSION_COPY.md`](./SUBMISSION_COPY.md) — English claim-safe source copy.
4. [`AGENT_ROLES.md`](./AGENT_ROLES.md) — three narrative roles and their
   authority boundaries.
5. [`../skills/README.md`](../skills/README.md) — six descriptors mapped to the
   frozen `DemoDataSource` port.
6. [`../docs/demo/DEMO_SCRIPT.md`](../docs/demo/DEMO_SCRIPT.md) — the English timed
   incident-to-recovery script.
7. [`CLAIMS.md`](./CLAIMS.md) — the release ledger and evidence gates.
8. [`../reports/tasks/T3.md`](../reports/tasks/T3.md) — task scope, checks, and
   remaining gaps.

## Truth rule

`CLAIMS.md` is the submission claim source of truth. A release may promote a
status only after the integrated candidate supplies the listed runtime and
visual evidence. Missing evidence requires a downgrade or removal.
